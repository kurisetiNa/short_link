# shortlink

根据截图参数创建的 Java Maven 项目。

- Java：17
- Build system：Maven
- GroupId：`com.nageoffer.shortlink`
- ArtifactId：`shortlink-all`

## 使用 IDEA 打开

1. 启动 IntelliJ IDEA。
2. 选择 **File → Open**。
3. 选择本项目的 `pom.xml` 或项目目录。
4. 在提示中选择 **Open as Project**。
5. 确认 **Project SDK** 为 JDK 17。
6. 打开 `src/main/java/com/nageoffer/shortlink/Main.java`，运行 `main` 方法。
